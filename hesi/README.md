# HESI site (branch of EFC2026)

New Hoover Education Success Initiative site, built from the Oct 14, 2026 approved design. Self-contained: everything it needs is inside this `hesi/` folder.

Upload the whole folder to the root of the EFC2026 repo. It will be live at `/EFC2026/hesi/` and opens from `index.html` (redirects to `home.dc.html`).

## Pages
- `home.dc.html` – Home
- `vision.dc.html` – National Vision (Vision + Council merged)
- `bibliography.dc.html` – Bibliography (linked from National Vision)
- `state-tools.dc.html` – State Tools (SEA Change intro + resources grid)
- `sea-change.dc.html` – SEA Change interactive plan
- `local-tools.dc.html`, `team.dc.html`, `contact.dc.html`
- `HesiHeader.dc.html`, `HesiFooter.dc.html` – shared nav and footer
